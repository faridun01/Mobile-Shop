# Планшеты: категории, SN и остатки — 18.10.2026

Изменения локальные, публикация не выполнялась. Рабочая БД не использовалась.

## Изменено

- В склад, продажу, перемещения и приход со склада добавлен общий переключатель категорий: телефоны, планшеты, аксессуары. В складе «Все устройства» объединяет телефоны и планшеты; аксессуары остаются отдельным количественным списком.
- При выборе планшетов в продаже, перемещении и приходе со склада сканер открывается в режиме SN; при выборе аксессуаров — в режиме штрихкода. При закупке планшета кнопка у SN всегда открывает режим SN, а не общий режим любого кода.
- Web и native используют общий распознаватель SN. Режим SN не принимает обычные числовые EAN/UPC/IMEI, умеет извлекать SN из подписанного составного QR и нормализует регистр. Сканер показывает отдельные режимы IMEI / SN / Штрихкод.
- Добавлена кнопка поиска аксессуара сканированием штрихкода. Поиск устройств явно обозначен как IMEI / SN, существующий поиск серийных номеров без учёта регистра сохранён.
- После сохранения прихода со склада явно обновляется общий список устройств. Раньше отправлялось событие, а обновление общего списка зависело от WebSocket. Обновление ждёт завершения предыдущего GET, чтобы не использовать старое расположение устройства из запроса, начавшегося до commit.
- Lookup прихода возвращает категорию устройства без закупочной стоимости. Выбранная категория прихода проверяется по ответу сервера, поэтому код другой категории не добавляется молча.
- Сообщение закупки указывает, что товар поступил на главный склад, и объясняет следующий шаг для другой точки.

## Остатки по складам

Закупка регистрирует товар на главном складе. Она не дублирует его в других магазинах. Для появления планшета в другой точке нужен приход со склада или перемещение. Это правило сохранено.

На отдельной тестовой БД проверен сценарий через HTTP:

1. Закуплен TABLET с SN `R58N-AUDIT-2026` и себестоимостью $123.45.
2. Подтверждено размещение на главном складе.
3. Lookup по SN в нижнем регистре вернул TABLET.
4. Планшет принят в отдельный магазин через `/store-receipts`; API остатков показал TABLET / STORE_STOCK в этой точке.
5. Выполнено перемещение в Сиёму; поиск по SN показал планшет в целевом магазине, категория и $123.45 сохранены.

## Ограничения сканирования

Проверена программная обработка результатов камеры; физические камеры iPhone/Android не проверялись. Это сканер закодированного SN (штрихкод/QR), не OCR обычной печатной надписи.

По одному числовому значению нельзя надёжно отличить серийный номер от товарного штрихкода. Чисто числовой SN без явной метки `SN:` внутри распознанного кода вводится вручную в поле SN; подписанный SN поддерживается. У других буквенно-цифровых кодов на коробке может быть та же символика, что у SN: нужно направлять рамку именно на код под надписью SN/S/N и сверять результат. Произвольная маркировка производителя не гарантирует автоматического различения без дополнительных данных о формате.

Автоматического исправления ранее ошибочно записанных SN или категорий в рабочих данных не выполнялось.

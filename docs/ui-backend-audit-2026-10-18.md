# Соответствие UI и backend — 18 октября 2026

## Область и среда

Проверены исходники UI и API, загрузка разделов под разными ролями, выбранные действия в настоящем Chrome и реальные записи в PostgreSQL. Использовалась отдельная локальная БД `mobile_shop_audit` на порту 55439. Каждый итоговый прогон создаёт схему `audit_fixes_ui_*`, применяет миграции и seed, запускает API с production frontend и WebSocket, затем удаляет схему. Рабочая БД не использовалась.

Это отчёт о фактически выполненных проверках. **Он не подтверждает, что каждая возможная кнопка во всех состояниях, комбинациях данных и на всех устройствах уже нажата и проверена.** Проверка наличия обработчика, открытие страницы и выполнение операции учитываются отдельно.

## Сверка записей после UI

Проведённый через UI приход телефона $60 сохранён в долг: суммарный долг поставщикам $60. Планшет `72255/Y5XH00021` оприходован в `store-siyoma`, категория TABLET сохранена.

Продавец продаёт исходный тестовый телефон с себестоимостью $50 за 1000 TJS при курсе 10. Проверки БД и отчёта подтверждают выручку $100, себестоимость $50, чистую прибыль $50, кассу магазина $100 и суммарную доступную прибыль владельцев $50. Баланс каждого созданного финансового счёта восстановлен из проводок и совпал с его сохранённым балансом; счета касс совпали со Store.cashBalanceUsd. **Необъяснённое расхождение в этом сценарии: $0.** Начальные устройства являются тестовыми остатками; полное равенство капитала и активов для этой небольшой UI-фикстуры не заявляется.

## Повтор и артефакты

- `npm run audit:ui-contracts` — карта исходников и привязок, БД и браузер не нужны.
- `npm run test:ui` — сборка, свежая тестовая схема, браузерные сценарии, сверка и удаление схемы. Требуется DATABASE_URL отдельной локальной БД с audit/test/ci в имени и Chrome/Chromium; нестандартный путь задаётся CHROME_PATH.
- `node --import tsx scripts/test-ui-audit.ts --actions-only` — повтор действий на уже собранном dist в новой схеме.
- `scripts/serve-ui-audit.ts` — ручной изолированный стенд.

В CI добавлены статическая проверка связей кнопок/маршрутов и браузерный набор после production build. Сам GitHub Actions в этой сессии не запускался; проверен локальный Windows-прогон. Для Linux используется CHROME_PATH=/usr/bin/google-chrome.

Машинные данные находятся в `output/ui-backend-audit/`: contracts.json, browser.json, actions.json, reconciliation.json, логи отдельных наборов и screenshots в screens/. Они локальны и не содержат токенов авторизации.

Физические iPhone/Android, Safari/WebKit, оптическое распознавание камерой, печать/нативный Share, все файлы экспорта и все возможные комбинации 632 мест с кнопками остаются вне подтверждённого покрытия. Для утверждения «каждая кнопка безошибочна» перечисленные пробелы необходимо закрыть отдельными сценариями; такого утверждения этот аудит не делает.

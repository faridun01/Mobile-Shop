# Unpaid Cash-Register Expenses Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a cash-register expense that exceeds a store's current cash balance be saved as `UNPAID` (notifying admins/partners) instead of being rejected outright, and let an admin/partner manually pay it later once the register has the cash — with owner profit only debited at the moment cash actually leaves the register.

**Architecture:** Add a `status`/`paidAt` pair to `Expense`. `createExpense`'s existing cash-guard `updateMany` (`cashBalanceTjs: { gte: amountTjs }`) already tells us in one atomic step whether the register can cover the amount — branch on its `count` instead of throwing when it's `0`. A new `payExpense` service function re-runs that same guard later and, on success, applies the owner-profit debit and ledger entry that `createExpense` would have applied immediately for a `PAID` expense. Both paths reuse a small `applyOwnerProfitDelta` helper (replacing three near-identical inline copies) and a `notifyRoles` helper that mirrors the existing `TransferRequest` notify pattern in `transfers.service.ts`.

**Tech Stack:** Express + Prisma (PostgreSQL) on the server, React + Zustand-backed context on the client, Vitest for server unit tests (mocked Prisma client, no live DB needed).

**Spec:** `docs/superpowers/specs/2026-09-16-unpaid-cash-expenses-design.md`

## Global Constraints

- Only the `paidFromCashRegister: true` + `storeId` set path changes. `paidFromCashRegister: false` ("Счёт компании") and no-`storeId` (`BUSINESS`) expenses keep behaving exactly as today (always immediate `PAID`).
- No automatic settlement on cash-in events (sales, refunds, exchanges, owner investment, manual balance edits) — paying an `UNPAID` expense is always an explicit admin/partner action.
- No partial payment — an expense is paid in full or the pay action fails with an error, same all-or-nothing shape as the existing cash guard.
- Owner profit (`totalAccruedProfitUsd`/`availableProfitUsd`) and the `LedgerEntry` for an expense are only ever created at the moment it becomes `PAID` (at creation if funded immediately, or via `payExpense` later) — never for an `UNPAID` expense, never twice for the same expense.
- Per-record USD convention: always use the expense's own stored `amountUsd`/`exchangeRate` snapshot, never re-derive from today's rate ([[feedback_reports_usd_daily_rate]] memory).
- The "Итого за период" totals on the Expenses page exclude `UNPAID` expenses entirely until they're paid.

```ts
/** Applies (or reverts, via sign: 1) a proportional profit delta to every owner. Shared by
 * createExpense, payExpense, updateExpense and deleteExpense so the same math lives in one place. */
async function applyOwnerProfitDelta(tx: TransactionClient, amountUsd: number, sign: 1 | -1) {
  const owners = await tx.owner.findMany();
  if (owners.length === 0) return;
  await Promise.all(
    owners.map((owner) => {
      const delta = roundMoney(amountUsd * (owner.profitSharePercent / 100)) * sign;
      return tx.owner.update({
        where: { id: owner.id },
        data: { totalAccruedProfitUsd: { increment: delta }, availableProfitUsd: { increment: delta } },
      });
    })
  );
}

/** Fans a notification out to every given role and broadcasts each one, mirroring the
 * TransferRequest notify pattern in transfers.service.ts. */
async function notifyRoles(
  tx: TransactionClient,
  roles: readonly ('ADMIN' | 'PARTNER')[],
  data: { title: string; message: string; targetId: string }
) {
  const notifications = await Promise.all(
    roles.map((targetRole) =>
      tx.notification.create({
        data: { title: data.title, message: data.message, targetType: 'EXPENSE', targetId: data.targetId, targetRole },
      })
    )
  );
  notifications.forEach((notification) => RealtimeSyncGateway.broadcast('NOTIFICATION_CREATED', notification));
}
```

```ts
export async function payExpense(id: string, actorId: string) {
  return prisma.$transaction(async (tx) => {
    const actor = await resolveActor(tx, actorId);
    const expense = await tx.expense.findUnique({ where: { id } });
    if (!expense) throw new Error('Расход не найден');
    if (expense.status !== 'UNPAID') throw new Error('Этот расход уже оплачен');
    if (!expense.storeId) throw new Error('У расхода не указан магазин для списания');

    const store = await tx.store.findUnique({ where: { id: expense.storeId } });
    if (!store) throw new Error('Магазин не найден');
    if (store.isMainWarehouse) throw new Error('Главный склад не является торговой кассой');

    const cashGuard = await tx.store.updateMany({
      where: { id: expense.storeId, cashBalanceTjs: { gte: expense.amountTjs } },
      data: { cashBalanceTjs: { decrement: expense.amountTjs } },
    });
    if (cashGuard.count !== 1) throw new Error('В кассе всё ещё недостаточно наличных для этого расхода');

    const updated = await tx.expense.update({
      where: { id },
      data: { status: 'PAID', paidAt: new Date() },
    });

    const amountUsd = expense.amountUsd ?? roundMoney(expense.amountTjs / (expense.exchangeRate || 1));
    await applyOwnerProfitDelta(tx, amountUsd, -1);

    await tx.ledgerEntry.create({
      data: {
        type: expense.category === 'Зарплата' || expense.category === 'SALARY' ? 'SALARY' : 'EXPENSE',
        description: expense.comment || expense.description || `Расход: ${expense.category}`,
        amountTjs: -expense.amountTjs,
        amountUsd: -amountUsd,
        exchangeRate: expense.exchangeRate ?? undefined,
        storeId: expense.storeId,
        storeName: store.name,
        userName: actor.name,
        referenceId: expense.id,
      },
    });

    await tx.notification.updateMany({
      where: { targetId: id, targetType: 'EXPENSE', resolved: false },
      data: { resolved: true, read: true, resolvedAt: new Date(), readAt: new Date() },
    });

    await notifyRoles(tx, ['ADMIN', 'PARTNER'], {
      title: 'Расход оплачен',
      message: `Расход [${expense.category}] на ${expense.amountTjs} TJS ($${amountUsd}) оплачен из кассы ${store.name}.`,
      targetId: expense.id,
    });

    await tx.auditLog.create({
      data: {
        userId: actor.id,
        userName: actor.name,
        userRole: actor.role,
        action: 'EXPENSE_PAID',
        details: `Оплачен ранее неоплаченный расход [${expense.category}]: ${expense.amountTjs} TJS ($${amountUsd}) (${store.name})`,
        financialDetails: { amountTjs: expense.amountTjs, amountUsd },
        targetId: id,
      },
    });

    return updated;
  }, { maxWait: 10000, timeout: 25000 });
}
```
